# WorkDaddy Releases

WorkDaddy 桌面端的发布仓库：安装包与自动更新清单（`workdaddy*.yml`）都挂在本仓库的
[Releases](https://github.com/geoly-ai/workdaddy-releases/releases) 上，应用内更新器从
`releases/latest/download` 拉取。

- 下载最新版：见 [Releases](https://github.com/geoly-ai/workdaddy-releases/releases/latest)
- 发布约定（维护者）：见主仓库 `docs/workdaddy/RELEASE.md`——发布不得勾选 pre-release，老版本不删

# WorkDaddy

**AI agent 桌面工作台 —— 打开页面、圈中问题、直接开问**

[官网 workdaddy.app](https://workdaddy.app) · [下载最新版](https://github.com/geoly-ai/workdaddy-ai/releases/latest)

WorkDaddy 是一个独立的 AI agent 桌面应用。内嵌浏览器打开你正在用的网站，选中页面上的任何内容直接向 agent 提问，agent 结合真实数据工具做解读与分析——不用截图、不用复制粘贴、不用切窗口。

- **所见即所问**：选中页面文字即成为提问上下文，agent 读的就是你看的
- **装上即用**：无强制注册，下载安装即可开始
- **模型自由**：支持任意 OpenAI 兼容端点与本地模型（Ollama / LM Studio），自带 key 即可
- **自动更新**：安装一次，后续版本应用内直接升级
